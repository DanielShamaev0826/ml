# Машинное обучение — практические работы №1–7

Репозиторий содержит решения практических работ по дисциплине «Машинное обучение» в варианте C.

## Структура проекта
- data/ — датасеты
- notebooks/ — Jupyter notebooks по практическим работам
- src/ — Python-скрипты
- figures/ — графики и визуализации
- requirements.txt — зависимости проекта

## Практическая работа №1
Настройка окружения и первичный анализ данных.

## Практическая работа №2
Разведочный анализ данных (EDA).

## Практическая работа №3
Сборка пайплайна предобработки.

## Практическая работа №4
Линейная регрессия и анализ качества модели.

## Практическая работа №5
Классификатор и метрики качества.

## Практическая работа №6
Классификация текстов.

## Практическая работа №7
Случайный лес, важность признаков и интерпретация модели.

## Среда
Python 3.12
Библиотеки: pandas, numpy, matplotlib, scikit-learn, seaborn, shap
